# BARON GOLD SIGNALS — النسخة الأولية

## ما الذي تفعله هذه النسخة؟
- لوحة عربية خاصة بالمدير.
- إنشاء صفقة BUY أو SELL يدوياً عبر خطوات.
- نشر الدخول ووقف الخسارة و3 أهداف في قناة `@baroan92`.
- أمر `/test` لإرسال رسالة اختبار.
- أمر `/cancel` لإلغاء إدخال الصفقة.
- رفض أوامر المستخدمين غير المدير.

## معلومات أمان مهمة
1. لا تضع توكن البوت داخل الكود.
2. أضف `BOT_TOKEN` كمتغير بيئة سري في منصة الاستضافة.
3. أضف `ADMIN_ID` وهو رقم حساب تيليغرام الخاص بالمدير، وليس اسم المستخدم.
4. أبقِ `CHANNEL_ID` على `@baroan92`.
5. لا تشارك التوكن أو رقم المدير علناً.

## معرفة ADMIN_ID
شغّل بوتاً موثوقاً يعرض Telegram user ID أو استخدم طريقة آمنة محلية/موثوقة للحصول على رقم حسابك. لا ترسل التوكن لأي بوت مجهول.

## النشر
هذا المشروع مهيأ كعامل دائم (Background Worker) على Render. العامل الدائم قد يتطلب خطة مدفوعة حسب شروط المنصة الحالية. لا تختَر خدمة ويب مجانية نائمة إذا كنت تريد استقبال أوامر على مدار الساعة.

## اختبار آمن
بعد ضبط المتغيرات وإضافة البوت مشرفاً بصلاحية نشر الرسائل:
- افتح البوت وأرسل `/start`.
- اختر شراء أو بيع وأدخل الأسعار.
- استخدم `/test` لإرسال رسالة اختبار.
ابدأ برسالة اختبار فقط قبل نشر أي توصية حقيقية.

## حدود النسخة
هذه نسخة النشر اليدوي فقط. لا تحتوي على تحليل سوق تلقائي أو ربط TradingView بعد. لا تنشر إشارات تلقائية قبل إضافة مصدر أسعار موثوق، قواعد تحليل محددة، واختبار تاريخي وتجريبي ومراقبة الأخطاء.
